Пульт KingBird: план дня и статус клонов

Четвёртый раунд с Fable и Codex, после ваших поправок. Рабочее имя в макетах — tutti, окончательное выбираете вы (ниже).

Граница инструмента: показывает состояние и помогает распределить работу. Не редактор и не чат с агентами: разговор с агентами и чтение кода остаются в Rider. Агентов он не запускает и с ними не общается.

Утреннее планирование

Распределение новой работы дня по проектам, клонам и редакторам. Задачи к вам приходят текстом (тикет, ссылка, скриншот), поэтому вход — простой список, который вы пишете сами.

1 · пишете списокtutti plan открывает в Rider файл today.md. Одна строка на задачу.
вы, 1–2 мин
2 · инструмент раскладываетКакой клон свободен, где занят — предлагает параллельный. Какие Unity нужны и не больше ли 4. Какие забытые сессии закрыть.
tutti
3 · подготовкаОткрывает Unity нужной версии (у вас их 4: от 2021.3 до 6000.3.25) и окно Rider на клоне, копирует команду старта, например /full-cycle ….
tutti, по кнопке
4 · работаНовая вкладка в Rider, claude, вставили команду. Имя задачи — имя сессии, по нему статус собирается под строкой плана.
вы, в Rider
# today.md — имя задачи · где начинать → куда переносить · нужен ли Oracle
- claw RT leak fix     BaseRun-parallel -> AWay, TowerKing   oracle
- shop reskin          BaseRun                               oracle
- tags refactor        GalaxyGuardians

Полезно, когда

  • две задачи претендуют на один клон или редактор
  • фича расходится на несколько проектов, и нужно видеть, где её можно проверить (вчера: «в BaseRun нет клешни, проверяем в AWay»)
  • нужно вспомнить, какую версию Unity открыть для какого клона

Станет ритуалом, если

  • планировать обязательно каждый день
  • файл надо держать в синхроне с реальностью (инструмент его только читает)
  • появятся оценки, расписание, ручное переключение стадий
  • задачу вне плана завести сложнее, чем по плану

Терминал или веб

TUI во вкладке Riderначать с этого

  • Живёт рядом с агентами, браузер не нужен
  • Go + Bubble Tea, один бинарник без зависимостей
  • Встраиваемый режим: без перехвата всего экрана (alt-screen) и мыши. Именно полноэкранный режим, по мнению Fable, глючит в терминале Rider (у herdr). Проверим первым делом
  • Запасной вариант — просто печать таблицы (tutti status)

  • Тот же бинарник: tutti web, без фонового сервиса
  • Выигрывает, когда хочется смотреть: diff, скриншоты full-cycle, план и статус рядом на втором мониторе

Модель данных у обоих общая, поэтому веб можно добавить позже без переделок. Все трое за то, чтобы начать с TUI.

План

  1. Проверка в терминале Rider. Крошечный Bubble Tea во встраиваемом режиме: перерисовка, ресайз, клавиши.
    30 мин
  2. Статус. Таблица клонов, сессий, REVIEW / забытых / свободных + tutti status текстом.
    полдня
  3. План дня. today.md, группировка статуса по задачам, открытие Unity нужной версии и окна Rider, копирование команды старта.
    полдня
  4. Неделя использования. Веб — только если захочется смотреть diff и скриншоты.
    —

Что решить вам

  1. Имя: одно из шести или своё.
  2. Формат строки в today.md подходит? «Откуда → куда» и пометка oracle.
  3. Сессии Codex показывать сразу?
